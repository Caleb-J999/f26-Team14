## Description
> Studio Share is a platform for small groups that need short-term access to specialized creative spaces.
> The app makes renting these spaces easier by allowing users to find and book available spaces in one place.
> The goal is to make creative spaces quicker and easier to discover while helping space owners reach potential renters.

## App Functions

1. Customer/Renter:
   1. Create/modify customer profile - Users can create and manage their account.
   2. View available spaces - Users can browse available creative spaces.
   3. Book available time slots - Users can check availability and reserve a time slot.
   4. View/manage bookings - Users can view and manage their reservations.

2. Provider/Space Owner:
   1. Create/modify provider profile - Space owners can manage their provider account.
   2. Create and edit listings - Providers can add and update creative space listings.
   3. Manage availability - Providers can set when their spaces are available.
   4. View/manage bookings - Providers can view and manage reservations for their spaces.

3. SysAdmin:
   1. Manage users - Administrators can manage customer and provider accounts.
   2. Moderate listings - Administrators can review and remove inappropriate listings.
   3. Monitor platform activity - Administrators can monitor activity on the platform.
   4. Remove inappropriate content - Administrators can remove content that violates platform rules.
